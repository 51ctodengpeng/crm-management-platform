# CRM 客户管理系统 · 安装与使用说明

面向使用 Windows 安装包的运维与业务人员。源码运行、Linux 部署不在本文范围内（见 `docs/deploy/`）。

---

## 1. 它是什么形态

安装包做了三件事，理解这三件事就不会踩坑：

1. **程序装进 Program Files**，普通用户改不动，避免误删；
2. **数据单独放在 `C:\ProgramData\CRM客户管理系统`**，因为 Program Files 不可写，放一起会导致服务起不来；
3. **注册成 Windows 服务（服务名 `CRMManager`）**，开机自启、后台运行、没有黑框窗口。

所以装完之后：桌面上有快捷方式，服务在后台跑，你只管用浏览器。

### 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / Windows Server 2016 及以上（64 位） |
| 权限 | 安装需要管理员；日常使用不需要 |
| 端口 | 默认 8081，装的时候可改 |
| 浏览器 | Chrome / Edge 最新版 |
| 磁盘 | 程序约 40 MB，数据按附件量增长 |

## 2. 安装

双击 `CRM客户管理系统_安装程序_v2.0.0.exe`，UAC 提示点「是」。

向导里只有两页需要你决定：

### 2.1 服务设置

| 选项 | 说明 |
| --- | --- |
| 访问端口 | 默认 `8081`。被占用就换一个（如 8090、9000） |
| 允许局域网访问 | 勾选后监听 `0.0.0.0`，并**自动在防火墙放通该端口**；不勾选则只有本机能打开 |

> 拿不准就保持默认：端口 8081 + 勾选局域网访问。这是团队共用的常见配置。

### 2.2 管理员账号

账号固定是 `admin`，这里设置的是**首次登录密码**：

- 至少 8 位，且同时包含字母和数字
- 不能用英文双引号（会破坏命令行传参）
- 登录后可以随时在系统里改

### 2.3 安装程序做了什么

按顺序执行，任一步失败都会在日志里留下痕迹：

1. 复制程序到 `C:\Program Files\CRM 客户管理系统`
2. 创建数据目录 `C:\ProgramData\CRM客户管理系统`
3. 写入 `installed.ini`（数据目录、监听地址、端口）
4. 用你设的密码初始化管理员账号
5. 注册服务 `CRMManager` 并设为自动启动
6. 启动服务、放通防火墙（如果勾了局域网）
7. 创建桌面与开始菜单快捷方式

### 2.4 无人值守安装（批量部署）

```bat
CRM客户管理系统_安装程序_v2.0.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART ^
    /PORT=8081 /LAN=1 /ADMINPWD=Abcd1234 /LOG=C:\install-crm.log
```

| 参数 | 含义 |
| --- | --- |
| `/PORT=8081` | 访问端口 |
| `/LAN=1` / `/LAN=0` | 是否允许局域网访问 |
| `/ADMINPWD=xxx` | 管理员初始口令；**不传此参数**时程序会自动生成 14 位随机口令，写入数据目录的 `初始管理员密码.txt` |
| `/DIR="D:\CRM"` | 改安装目录（一般不用） |
| `/LOG=路径` | 记录安装日志，排障必备 |

静默安装不会弹任何对话框，适合域内批量推送。

## 3. 首次登录

1. 双击桌面「CRM 客户管理系统」，浏览器会打开 `http://127.0.0.1:8081/`
2. 账号 `admin`，密码是安装时设的
3. 登录后立刻做两件事：**修改密码**（右上角头像 → 修改密码）、**补全个人信息**

> 如果你是静默安装且没给 `/ADMINPWD`，密码在
> `C:\ProgramData\CRM客户管理系统\初始管理员密码.txt`，登录后请删掉这个文件。

## 4. 日常使用

| 入口 | 位置 |
| --- | --- |
| 打开系统 | 桌面快捷方式 / 开始菜单 → CRM 客户管理系统 → 打开管理界面 |
| 使用说明 | 开始菜单 → 使用说明（安装目录里的 txt） |
| 数据目录 | 开始菜单 → 数据目录 |
| 服务管理 | 开始菜单 → 服务管理（services.msc），找到 `CRM 客户管理系统` |

### 服务常用命令

```bat
sc query CRMManager          :: 看状态
net start CRMManager         :: 启动
net stop CRMManager          :: 停止
sc config CRMManager start= demand   :: 改成手动启动（不再开机自启）
```

改「手动启动」后，需要时在 services.msc 里点启动，或双击桌面快捷方式前先启动服务。

## 5. 改端口 / 限制访问范围

配置在安装目录的 `installed.ini`（需管理员权限编辑）：

```ini
[CRM]
DataDir=C:\ProgramData\CRM客户管理系统
Host=0.0.0.0
Port=8081
```

| 键 | 取值 | 说明 |
| --- | --- | --- |
| `Host` | `0.0.0.0` | 局域网内其他电脑可访问 |
| | `127.0.0.1` | 只有本机能访问 |
| `Port` | 1024–65535 | 端口被占用时换一个 |

改完必须重启服务：`net stop CRMManager && net start CRMManager`

> `DataDir` 不要轻易改。要迁移数据，见第 6 节的做法，改完这个键还得把旧数据拷过去。

## 6. 数据、备份与迁移

数据全在 `C:\ProgramData\CRM客户管理系统`：

| 内容 | 说明 |
| --- | --- |
| `crm.db` | 数据库：客户、项目、合同、回款、用户、日志全在这一个文件里 |
| `uploads\` | 合同、发票、Word/PPT 等附件 |
| `avatars\` | 用户头像 |
| `.secret_key` | 加密密钥。**丢了之后数据库里加密过的字段就解不开** |
| `logs\` | 运行日志、服务日志、备份日志 |
| `初始管理员密码.txt` | 仅自动生成口令时出现，登录后请删除 |

**备份**（推荐先停服务，保证 `crm.db` 处于一致状态）：

```bat
net stop CRMManager
robocopy "C:\ProgramData\CRM客户管理系统" "D:\backup\crm-20261020" /E /COPYALL
net start CRMManager
```

嫌停机麻烦的话，系统内也自带备份功能（设置 → 备份），按天留档，可在界面里恢复。

**迁移到另一台机器**：装好新机器 → 停两台机器的服务 → 把整个数据目录拷过去覆盖 → 启服务。

## 7. 升级

直接运行新版本的安装程序：

- 检测到旧版本会提示「覆盖升级」，选「是」
- 程序文件被替换，**数据目录不动**，原有客户与附件都在
- 安装程序会先停服务再替换文件，避免占用

升级前建议按第 6 节做一次备份——升级本身不会动数据，但备份是唯一后悔药。

---

## 8. 卸载

三种方式任选：

- 开始菜单 → CRM 客户管理系统 → 卸载
- 控制面板 → 程序和功能 → CRM 客户管理系统
- 安装目录下的 `unins000.exe`

卸载会自动：停止并删除服务 → 删除防火墙规则 → 删除程序文件与快捷方式。

**数据目录默认保留**（这是刻意的，防止删程序连带删客户数据）。确认不再需要时，手工删除 `C:\ProgramData\CRM客户管理系统`。

## 9. 排障

| 现象 | 原因与处理 |
| --- | --- |
| 浏览器打不开，服务显示「正在运行」 | 端口被别的程序占用或 `installed.ini` 端口与实际不符；用 `netstat -ano \| findstr 8081` 核对 |
| 服务启动后立刻停止 | 看 `C:\ProgramData\CRM客户管理系统\logs\service.log`；常见是数据目录权限或端口冲突 |
| 忘了管理员密码 | 管理员身份运行：`"C:\Program Files\CRM 客户管理系统\CRM客户管理系统.exe" --reset-admin 新密码` |
| 同事打不开 | ① `Host` 是否为 `0.0.0.0`；② 防火墙是否放通端口；③ 是否同网段 |
| 升级后数据不见了 | 大概率是数据目录变了。检查 `installed.ini` 的 `DataDir` 是否指向原目录 |
| 安装时提示服务注册失败 | 是否以管理员身份运行安装程序；杀软是否拦截了服务创建 |
| 上传附件失败 | 检查数据目录剩余空间与 `uploads` 目录权限 |

服务日志位置：`C:\ProgramData\CRM客户管理系统\logs\service.log`
安装日志：静默安装时用 `/LOG=路径` 指定，交互安装可加 `/LOG` 生成在临时目录。

## 10. 安全建议

1. **不要直接映射到公网。** 本系统是内网工具，HTTP 明文传输。要从公网访问，前面加一层带 HTTPS 的反向代理（Nginx / IIS），并且只放通必要的来源 IP。
2. **HTTPS 是必须的**，一旦出内网就必须上证书，否则登录口令在链路上可见。
3. **别用 admin 日常操作。** 给同事开普通账号，按需分配数据范围；admin 只用来做管理。
4. **定期备份**，且备份要放到另一台机器或另一块盘上——放同机会跟着一起丢。
5. **保护 `.secret_key`。** 它和数据在一起，拿到数据目录的人等于拿到全部明文。备份文件的权限也要收紧。
6. **升级依赖注意**：本安装包已内置运行时，不要往安装目录里手工装 Python 包。
